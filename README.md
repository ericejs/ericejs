### ⭐ LiteDesk — Sistema de Gestão de Chamados

**Em desenvolvimento**

Sistema web para gerenciamento e atendimento de chamados técnicos, inspirado em situações reais de suporte de TI.

- Gestão de chamados e usuários.
- Perfis de acesso: Solicitante, Técnico e Administrador.
- Dashboard para acompanhamento de chamados.
- Integração entre Front-end, API e banco de dados.

**Tecnologias:** HTML, CSS, JavaScript, Node.js, Fastify e PostgreSQL.
